# JavaScript - Function Exercises

A practical JavaScript exercise focused on functions, arrays, objects, and array methods.

## About the Project

This project was developed as part of my JavaScript studies. The main goal is to practice creating functions and manipulating arrays of objects through practical challenges.

The exercise simulates a simple product inventory system.

## Challenges

The project contains four challenges:

### 1. List Products
Create a function that lists the products available in the inventory.

### 2. Search for a Product
Create a function that receives a product name, searches for it, and returns the matching product.

### 3. Filter Available Products
Create a function that returns only products with a stock quantity greater than zero.

### 4. Calculate Inventory Value
Create a function that calculates the total inventory value based on each product's price and stock quantity.

## JavaScript Concepts

The following concepts and methods were practiced:

- Functions
- Parameters and return values
- Arrays and objects
- `forEach()`
- `find()`
- `filter()`
- `reduce()`
- Arrow-free callback functions
- Conditional logic
